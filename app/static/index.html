API Endpoints

GET/api/v1/prices/latest?symbol=AAPL

Latest price with intelligent caching

GET/api/v1/prices/history/AAPL?hours=24

Historical prices, up to 7 days

GET/api/v1/prices/moving-average/AAPL?period=5

Moving average, Kafka or on-demand

POST/api/v1/prices/poll

Start a background polling job

GET/api/v1/prices/poll/{job_id}

Check polling job status

DEL/api/v1/prices/poll/{job_id}

Stop a polling job
